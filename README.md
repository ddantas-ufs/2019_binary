# 2019_binary
Benchmark comparison of VisionGL, Python, MATLAB, and Leptonica. Code used in conference paper published in HPCS 2019 [1].

Requires library [VisionGL release v0.1 from GitHub](https://github.com/ddantas/visiongl/releases/tag/v0.1).
